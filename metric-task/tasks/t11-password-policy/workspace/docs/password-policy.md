# Password policy for privileged accounts

Every privileged account password must satisfy all rules below. Report a failed rule by its code.

| Code | Rule |
|---|---|
| LENGTH | at least 12 characters |
| UPPER | at least one uppercase letter (A-Z) |
| LOWER | at least one lowercase letter (a-z) |
| DIGIT | at least one digit (0-9) |
| SYMBOL | at least one of `! # % * + - = ? @ ^ _ ~` |
