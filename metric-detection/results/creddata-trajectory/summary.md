# CredData-trajectory test: 시스템 커밋 × ML 모델

지표 정의 (채점 채널 prompt, instructions, tool_output만 센다):

- **recall** = 다 가려진 정답 span / 정답 span. 정답 span의 글자가 모두 가려졌으면 찾은 것으로 센다(채점기의 exact와 over). 일부만 가려졌거나(partial) 하나도 안 가려졌으면(missed) 못 찾은 것이다.
- **precision** = 가린 글자 가운데 정답 글자의 비율. item마다 원문 좌표에서 가린 글자 = edit가 바꾼 글자의 합집합, 가린 정답 글자 = 그 가운데 정답 span 안에 있는 글자를 세고, Σ 가린 정답 글자 / Σ 가린 글자로 계산한다. fail-closed로 차단된 item은 item 글자 전체를 가린 것으로 센다.
- **F2** = 5PR / (4P + R). recall에 precision보다 4배 무게를 둔다.
- 예전 지표는 summary.csv에 남겼다: exact_recall = 정확히 가린 정답 / 정답, edit_precision = 정답 span 하나 안에 든 edit / 전체 edit, exact_f2 = 그 둘의 F2.

`base`는 ML 어댑터를 끈 커밋 그대로다. `-`는 그 조합이 행렬에 없거나 결과가 없다는 뜻이다. 조건은 RUN_NOTES.md.
