# 지표 3: KEEP 판단 정확도

Task-aware 마스킹에서 과제에 필요한 비밀을 남기는 판단이 맞았는지 평가할 데이터를 보관할 폴더다.

현재는 준비용 폴더이며, 2단계에서 데이터셋·스키마·정답 기준을 설계할 예정이다.

정답은 지표 1과 따로 매긴다. 지표 1의 정답은 "실제로 인증에 쓰이는 자격증명인가"이고([정답의 정의](../metric-1/README.md#정답의-정의)), 지표 3은 그 자격증명 span마다 "세션의 과제에 필요한가"(KEEP/MASK)를 붙인다. 과제가 있어야 매길 수 있으므로, 과제가 없는 CredData 파일 조각에는 붙이지 않는다.
